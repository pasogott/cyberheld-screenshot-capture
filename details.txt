1. Email Extraction from Web Pages
   * Automatically detect and extract email addresses from any web page.
   * Extract emails from AJAX-loaded content (e.g., Google Search, LinkedIn, Gmail, Google Maps, etc.).
   * Extract cloaked or obfuscated emails (e.g., "user [at] domain [dot] com").

2. Automation & Filtering
   * Filter duplicate email addresses to ensure only unique ones are stored.
   * Allow users to extract emails based on a specific domain (e.g., all emails ending in @example.com).
   * Extract emails from local HTML documents and text files.

3. User Interface & User Experience
   * Simple popup UI with options to extract, view, and manage emails.
   * Display a list of extracted email addresses in a scrollable panel.
   * Ability to copy all extracted emails to the clipboard with one click.

4. Storage & Export Options
   * Save extracted emails to local storage for later retrieval.
   * Export extracted email lists to a .txt or .csv file.
   * Download stored email addresses with a single click.

5. Keyboard Shortcuts & Commands
   * Enable a keyboard shortcut (e.g., Ctrl+Shift+E) to extract and copy emails instantly.

6. AutoVisit Feature
·          Create a queue of URLs for automatic visiting and email extraction.
·          Allow users to define delay intervals between visits.
·          Automatically extract URLs from Google Search results and add them to the automation list.

7. Email Storage & Tracking
·          Enable users to review and manage extracted emails along with their source URLs.
